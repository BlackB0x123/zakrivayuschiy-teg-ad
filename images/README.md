# Изображения

`van.png` — иллюстрация фургона, извлечённая из первого фрейма предоставленного макета `figma/zakr/01_desktop.png`. Рамки и исходный текстовый лейбл удалены из вырезки: рамку и подписи рисует страница. Восемь карточек используют один исходник и разные CSS-фильтры, как в макете.

`apple-touch-icon.png` (180×180) и `favicon.ico` (16, 32, 48 px) — растровые версии пиксельного знака из `svg/favicon.svg`.
